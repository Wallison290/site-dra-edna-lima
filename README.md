# Site Dra. Edna Lima

Projeto em Next.js preparado para publicação na Vercel.

## Publicar pela Vercel

1. Extraia o arquivo ZIP.
2. Envie a pasta para um repositório GitHub ou importe o projeto pela Vercel.
3. A Vercel reconhecerá automaticamente o framework **Next.js**.
4. Não é necessário cadastrar variáveis de ambiente.
5. Clique em **Deploy**.

## Executar no computador

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Comandos

- `npm run dev`: ambiente local.
- `npm run build`: valida e gera a versão de produção.
- `npm run start`: executa a versão de produção.
- `npm run lint`: verifica o código.

As imagens utilizadas pelo site estão em `public/images`.
